## 3. 取り込むときに守ってほしいこと

### ファイル名を変えない

ノート間のリンクは `[[概念の和名]]` という形で、**ファイル名と一致させてあります**。
リネームすると 267 本のリンクが切れます。Obsidian の「リンクを自動更新」設定が
有効なら追従しますが、一括で機械的にリネームする場合は切れます。

### 本文を書き換えない

`## 本文` の中身は、**実際に発行された新聞の文章そのもの**です（掲載済み39本）。
誤字に見えるものも原文のままにしてください。文字単位で出典と一致することを
確認済みです。

神山さんご自身の考えを書き足す場合は、`## 本文` の中ではなく、末尾に
`## メモ` などの見出しを立てて追記することをおすすめします。そうすれば
後日この書き出しをやり直しても、追記だけを残して差し替えられます。

### 未解決リンクは正常です

`[[...]]` のリンク先は **91種類**あり、そのうち **52種類はまだノートがありません**。
これは壊れているのではなく、Tribune の概念プール（全268概念）のうち今回
書き出したのが62本だからです。

Obsidian では未解決リンクはグレー表示になり、クリックすると空ノートが作られます。
**そのままで問題ありません。** グラフビューでは「まだ書かれていない概念」として
見えるので、次に何を取り込むかの手がかりになります。

未解決リンクの例: アフォーダンス / アリストテレス / カント / エントロピー など

### 既存ノートとの名前衝突に注意

保管庫にすでに「暗黙知」「創発」などのノートがある場合、同名ファイルになります。
**上書きする前に必ず神山さんに確認してください。**
衝突しそうなら、いったん `Tribune/概念/` のようなサブフォルダに入れて取り込み、
既存ノートとの統合は後から手作業で判断するのが安全です。

### ファイル名に括弧・中黒を含むもの（7本）

`制作知（ポイエーシス）` `観想知（テオリア）` `実践知（プロネーシス）`
`メティス（実践的狡知）` `情報量（シャノン情報）` `配慮（ゾルゲ）`
`ジョブ・クラフティング`

全角括弧と中黒はファイル名として有効ですが、一部の同期ツールやスクリプトが
嫌うことがあります。取り込み後にこの7本が開けるか確認してください。

## 4. 取り込み後にできること

- `tags:` に `concept` が付いているので、`tag:#concept` で全件を絞り込めます
- `掲載済み` / `未掲載` タグで、紙面に出たものと先行作成分を区別できます
- `domain_top` でグループ化すると、現象学10・経営学7・古代哲学6 が厚い塊になります
- Dataview プラグインを使うなら、`published_on` で時系列表が作れます

```dataview
TABLE domain, published_on, difficulty
FROM #concept
SORT published_on ASC
```

## 5. 追加分を後から書き出すには

Tribune は **毎日1件ずつ**新しい概念を紙面に出しています（全268概念のうち
2026-09-22 時点で139件が掲載済み）。あとから追加分を書き出す場合は、
Tribune のリポジトリで次を実行します。

```bash
cd ~/projects/tribune

# 掲載済みの全件を書き出す（LLM 不要・無料）
python3 -m scripts.tools.export_obsidian_concepts --all --out /path/to/出力先

# 特定のものだけ: CSV の Obsidian 列に 〇 を付けてから
python3 -m scripts.tools.export_obsidian_concepts --out /path/to/出力先
```

未掲載の概念を先行作成したい場合のみ、LLM を使います（1概念あたり約 $0.018）。

```bash
python3 -m scripts.tools.generate_unseen_concepts --dry-run   # 件数と見積もり
ANTHROPIC_API_KEY=sk-ant-... python3 -m scripts.tools.generate_unseen_concepts
```

書き出しは同名ファイルを上書きします。`## メモ` などの追記がある場合は
**上書きされて消えます**。追記を保護したい場合は、出力先を一時フォルダにして
差分を確認してからマージしてください。
